Microsoft DP 系列認證

DP (Data Associate) 系列是針對 Azure 雲端平台上的資料處理與人工智慧所設計的專業認證。

DP-203: Azure Data Engineer Associate

資料工程師的首選。涵蓋了資料整合、轉換、儲存與優化，重點在於 Azure Synapse Analytics, Data Lake, 與 Databricks 的應用。

DP-100: Azure Data Scientist Associate

適合資料科學家。重點在於如何在 Azure Machine Learning 環境中訓練、評估與部署機器學習模型。

DP-900: Microsoft Azure Data Fundamentals

入門認證，適合想要瞭解雲端資料概念（如結構化與非結構化資料）的初學者。
